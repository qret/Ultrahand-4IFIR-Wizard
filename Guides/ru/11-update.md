# Обновление

Тюнер умеет обновляться сам, не вынимая карту.

## Как обновить

1. **`Check for updates`** в корне меню — тюнер сходит на GitHub и скажет, есть ли
   новая версия.
2. Есть — появится пункт **`Update`**. Его надо **удержать**.
3. Перезапустите оверлей. Настройки разгона применяются при перезагрузке консоли —
   для этого есть `Reboot the console`.

Настройки разгона при обновлении **тюнера** не меняются: они лежат в файле прошивки,
а наш архив его не трогает.

> [!WARNING]
> С обновлением **самого 4IFIR** всё наоборот: там этот файл заменяется целиком,
> и разгон сбрасывается к заводскому. [Об этом ниже](#если-обновляете-сам-4ifir).

## Что обновляется

Только сам пакет настройки. Прошивка, загрузчик и оверлей 4IFIR остаются как были —
мы их не трогаем ни при установке, ни при обновлении.

**Движок оверлеев тоже остаётся как был.** Его ведёт автор прошивки, и обновляется он
вместе со сборкой 4IFIR; в нашем архиве его нет, так что ни комбинация вызова, ни тема,
ни порядок оверлеев, ни звук от обновления тюнера не меняются.

> [!NOTE]
> Тюнер проверяет версию структуры настроек и откажется работать, если она незнакомая.
> Это защита: писать значения по чужой раскладке — верный способ получить консоль,
> которая не грузится.
>
> **Заперты вы при этом не будете.** Настройки скрыты, а `Check for updates`
> и `Update` остаются на экране и работают. Нажмите первое: если вышла сборка под
> вашу прошивку, второе её поставит, и тюнер снова заработает.

## Порядок, если обновляете всё сразу

Когда обновляется всё, порядок такой:

1. **4IFIR** — сама сборка.
2. **Системная прошивка** консоли.
3. **Наш пакет**.

Первые два местами не менять: руководство 4IFIR предупреждает, что при обратном порядке
консоль просто не запустится. Наш пакет идёт последним, чтобы увидеть уже новую структуру
настроек.

## Если обновляете сам 4IFIR

Это делается не нашим тюнером, а отдельной программой — **All-in-One Switch Updater**,
он лежит в сборке и запускается из Homebrew Menu.

> [!IMPORTANT]
> **Перед обновлением 4IFIR обязательно снимите копию настроек** —
> `Service → Backup manager → Create backup`. Обновление заменяет файл настроек
> прошивки целиком, и весь разгон вернётся
> к заводскому.
>
> Копия при этом уцелеет: она лежит отдельно, и обновление про неё не знает. После
> обновления восстановите её из тюнера.

Порядок в самой программе — два захода подряд, и первый пропускают чаще всего:

1. `Custom Downloads` → **`Refresh`** → продолжить;
2. `Custom Downloads` → **`4IFIR`** → продолжить.

На вопросы отвечайте так: перезаписать `.ini` — **да**, переустановить hekate — **нет**.
После второго захода консоль перезагрузится сама.

Запускать программу надо в режиме полной памяти — удержите `R`, запуская любую игру.
Иначе загрузка прошивки откажется работать.

**Что переживает обновление, а что нет:**

| | |
|---|---|
| настройки разгона (наш тюнер) | **сбрасываются**, восстанавливайте из копии |
| копии настроек | остаются |
| тайминги `EMC Magician` | остаются, они хранятся отдельно от прошивки |

## Перед обновлением

Сделайте копию настроек — **`Service → Backup manager → Create backup`**.
Для обновления самого тюнера
это перестраховка, для обновления 4IFIR — обязательный шаг.

## Если обновление не находится

Проверьте подключение к сети. Тюнер обращается к GitHub напрямую; если у вас
ограничен доступ, обновление придётся скачать вручную и распаковать на карту,
как при первой установке.
