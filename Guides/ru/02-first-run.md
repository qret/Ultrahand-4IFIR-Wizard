Открыли оверлей (**`L` + `R` + `↑`**) — он показывает список оверлеев. Нажали **вправо**,
попали в список пакетов, зашли в **4IFIR Wizard**. Разберёмся, что здесь есть.

## Как устроено меню

```
eBAMATIC Stage        ← общий режим автоматики
Advanced              ← всё по узлам
  ├ CPU
  ├ GPU
  ├ RAM
  ├ Micro-Enhance Logic  ← тонкая настройка и аварийный доступ
  └ Fan Control          ← кривая охлаждения
Service               ← копии, импорт, сброс, сведения о консоли
Current Settings      ← что записано прямо сейчас
Check for updates     ← спросить GitHub о новой сборке
Update                ← появляется, только когда новая сборка есть
Reboot the console    ← перезагрузка
```

Порядок не случайный: сверху то, что нужно всем, ниже — то, что нужно немногим.

## Первое, что стоит открыть

**`Current Settings`** — сводка того, что реально записано в файле настроек.

Здесь важно понимать разницу. Пункт меню показывает, **что выбрано**. Сводка
показывает, **что записано**. Если консоль правили другим инструментом или
восстанавливали копию, расходиться будут именно эти два.

Сводка листается влево-вправо: на второй странице лежит кривая напряжений видеоядра
целиком и тонкие регуляторы памяти, на третьей — тайминги EMC Magician.

### Третья страница: тайминги EMC Magician

Страница `Magician` показывает тайминги памяти, которые вы сохранили в
[`EMC Magician`](09-timings.md#emc-magician--настройка-прямо-во-время-работы). Тюнер их
не пишет: они лежат у прошивки в `/config/4IFIR/emc_timings.ini`, страница только читает.
В тот же файл тюнер пишет лишь два напряжения, `VDDQ` и `VDD2`, —
[о них в главе про память](08-ram.md#vddq-и-vdd2--напряжения-профиля-optimized).

- **Что видно.** Набор для той частоты памяти и того `eBAL`, что сейчас записаны
  в прошивке. Magician называет профиль по `CL`, а страница пишет вместо него `eBAL` —
  это одно и то же: `CL = eBAL × 2 + 8`. Тайминги профиля Optimized показываются, только
  если `sMeh 8 E-Boost` стоит в `2`; их частота в заголовке — `1600 MHz` или `1331 MHz`,
  смотря по `Optimized Target`. Тайминг, который вы в Magician не трогали, отмечен `Auto`.
- **Строка сверху** подсказывает кнопки так же, как нижняя строка оверлея: значок кнопки
  и действие.
- **Кнопка `A`** (`Show MC` / `Hide MC`) — показать или спрятать значения арбитра (MC):
  они встают через точку рядом с таймингом.
- **Кнопка `Y`** (`Profiles`, `Next page`, `Current timings`) — сохранённые профили
  по возрастанию частоты, страницами: каждое нажатие
  показывает следующую страницу, после последней возвращаются текущие тайминги.
  Строка сверху говорит, какие профили из скольких сейчас на экране.
- **Сброс вида.** Ушли на другую страницу, вышли кнопкой `B`, зашли заново или закрыли
  оверлей — страница снова показывает текущие тайминги без MC.
- **Пустая страница** с пояснением — значит, в Magician пока ничего не сохранено.
  При `eBAMATIC` частоту выбирает прошивка, и текущий профиль не определить — смотрите
  все профили через `Y`.

Работает на Mariko и на Erista и понимает файл старого формата — такие значения помечены
`old format`.

> [!NOTE]
> Третья страница есть только на движке из набора первой установки
> ([Установка](01-install.md)). На другом движке сводка остаётся из двух страниц.

## Второе — знайте, как откатиться

**`Service → Restore Factory Defaults`** возвращает все настройки разгона к заводским.
Перед применением тюнер покажет, что именно изменится.

Этого достаточно, пока вы не настроили ничего своего: терять нечего, а заводское
состояние всегда под рукой.

Копия настроек (`Service → Backup manager → Create backup`) нужна позже и для
другого — **сохранить
удачную настройку**, чтобы вернуться к ней после новых опытов. Сброс вернёт заводское
и отбросит вашу работу; копия вернёт именно вашу.

## Что значит «применилось»

Тюнер пишет значение в файл настроек. Прошивка читает этот файл **при запуске**.

Значит после любой правки нужна **перезагрузка**. Пункт `Reboot the console` внизу меню —
для этого.

> [!NOTE]
> Пока не перезагрузились, консоль работает на старых настройках, а сводка уже
> показывает новые. Это не ошибка: сводка честно показывает, что записано в файле.

## Ревизия консоли

Тюнер сам определяет, Mariko у вас или Erista, и показывает **только те настройки,
которые к вашей консоли относятся**. Часть пунктов у разных ревизий разная — например,
у предела напряжения видеоядра разные диапазоны.

Поэтому не удивляйтесь, если у знакомого в меню есть пункт, которого нет у вас.
И не переносите чужие числа вслепую.

## Если что-то непонятно

У многих пунктов есть встроенная справка — она объясняет, что делает настройка
и в каких пределах её можно менять. Справка порождается из той же карты, по которой
собран сам тюнер, поэтому она не может разойтись с меню.
